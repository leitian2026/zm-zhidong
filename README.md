# 手机助手（PhoneAgent）

多模型（Gemini / GPT / Claude）聊天客户端，界面仿 QQ，工具/思考折叠条仿 Claude 网页版。
模型可以通过 root 直接操作这台手机（通过 root shell 执行任意操作）。

## 构建（GitHub 手动构建发布版）
1. 把整个文件夹上传到你的 GitHub 仓库（建议私有仓库，因为里面带了签名密钥 `app/release.jks`）。
2. 打开仓库 → Actions → **Build Release APK** → **Run workflow**。（只有手动触发，不会自动构建）
3. 构建完成后，在该次运行页面底部的 Artifacts 下载 `PhoneAgent-release`，里面是已签名的 release APK。

R8 目前关闭。稳定后在 `app/build.gradle.kts` 把 `isMinifyEnabled` 和 `isShrinkResources` 改成 `true`。

## 使用
1. 安装后打开 → 左上角菜单 → 设置，填入至少一家的 API Key（模型名可改）。
2. 设置里点「测试 root」，在 root 管理器里授权。
3. 回到聊天页，输入“关闭 Wi-Fi”之类的指令。输入框左边的按钮可切换模型。

## 工具与确认
- 只有一个工具 `run_shell`，手机上的所有操作都由模型用 root shell 完成，不再为每个功能单独写工具。
- App 不做任务判断，只有一个兜底：命令里含删除操作（rm / rmdir / unlink / shred / find -delete / pm uninstall / pm clear）时，对话里弹确认卡片，点“允许”才执行（120 秒无操作视为拒绝）。其余命令一律直接执行。
- 设置里关闭“自动放行非删除命令”后，进入严格模式，所有操作都要点确认。

## 划动手感
- 聊天列表的划动起步距离缩小到系统默认的一半（`UiChat.kt` 里的 `SCROLL_SLOP_FACTOR`，0.5 = 一半；想更跟手可改小，但太小点按钮容易被判成划动）。

## 终止
- 模型操作中（含等待确认、思考中），对话里的状态条右侧有“终止”按钮；输入框右边的方块也一样。
- 点击后立刻取消本轮：断开模型请求，并结束正在执行的命令，状态条显示“已终止”。

## 经验笔记（自主学习）
- 模型走了弯路才办成的事，会自己用 `run_shell` 记进笔记目录（应用私有目录下的 `files/notes/`）：`index.md` 是索引，每条一行，详细内容在单独文件里。
- 每次发送消息时，App 只做一件事：把 `index.md` 读出来拼进系统提示，不做任何判断。模型下次遇到类似的事先看索引、再读对应文件，直接用验证过的做法。
- 要不要记、记什么、合并和清理，全由模型决定；系统提示要求只记“不查就想不到”的、且验证成功过的做法，笔记里的命令失效就改掉或删掉，索引超过 40 行先合并。
- 笔记只是参考，不是指令。设置页里有“经验笔记”卡片，可以查看、修改、删除（删除时会同步去掉索引里对应的行）。

## 联网代理 / 工具 / 密钥（root 扩展能力）
- root 进程（`su`）通常不走 VPN。设置页「联网代理」填 VPN 软件的本地端口（如 `127.0.0.1:7890`，只有 SOCKS 时填 `socks5h://127.0.0.1:10808`），App 会在每条 root 命令前自动 export `http_proxy/https_proxy/ALL_PROXY`。卡片里有「测试连接 Cloudflare」按钮。
- 模型自己的扩展都放在 `/data/local/tmp/ext/`（不在 App 私有目录，**卸载重装后仍保留**）：`bin/` 每条命令都在 PATH 里；`env.sh` 存在就在每条命令前 source（模型可往里加 PATH/别名/变量，设置页「扩展环境」可一键停用）；`README.md` 是模型自己写的“装了什么、怎么用”清单，每次对话开头原样附进系统提示；经验笔记也搬到了 `ext/notes/`（旧笔记首次运行时自动复制）。App 不认识任何具体工具，只提供这几个通用钩子。
- 缺工具时模型先看清单和 `command -v`，没有再下载静态 arm64 二进制到 `ext/bin`，装好立刻更新 README.md；需要完整 Linux 环境时可下载 Alpine minirootfs 并 chroot。
- `run_shell` 新增可选参数 `timeout`（秒，默认 30，最大 600），下载大文件用。
- 设置页「密钥」：填名称和值，App 写入 `/data/local/tmp/secrets/名称`（目录 700、文件 600）。系统提示里只列名称，模型用 `$(cat 文件)` 取值，值不会出现在聊天里。
- 确认规则新增：`curl -X DELETE/PUT/PATCH`、`chmod +x`、`chroot`、`mount`、`| sh` 也会弹确认卡片。注意：运行已装好的脚本/二进制（只写名字）识别不出来，不会弹确认。

## 备份 / 还原
- 设置页「备份 / 还原」：把整个 `/data/local/tmp/ext`（工具、env.sh、README.md、笔记）打成一个 .tar.gz，用系统文件选择器存到任意位置；也可从任意位置选回来，解到 `/data/local/tmp`，即它们原来使用的位置（同名覆盖、其余保留）。
- 可勾选“同时包含密钥”（`/data/local/tmp/secrets`，明文），默认不带。
- 还原只接受 `ext/`、`secrets/` 开头且不含 `..` 的条目。`ext` 下有挂载点（chroot 没卸载）时导出会被拒绝。
- 换手机/恢复出厂后：装 App → 设置里还原备份 → 重新填 API Key 即可。

## 额度保护
- 设置里每家可填“每分钟 / 每天请求上限”（Gemini 默认 15 / 500，请按 AI Studio「速率限制」页面里自己模型那一行改，0 = 不限制）。
- 本分钟快满时 App 会先等一等再发（预留 2 次余量）；用到上限 80% 时输入框上方提醒；这些只统计本应用发出的请求。
- 真遇到 429：每分钟限制按服务端给的时间自动重试（最多 3 次），每日限制直接提示并给出重置时间。

## 动画
所有过渡统一 350ms + 同一条曲线（`Motion` 对象在 `UiBits.kt`），流式文字按帧匀速出字。
